# lilOS community

Apps and kernel modules for [lilOS](https://github.com/GexyLab/lilos), with their sources open to everyone. Anyone can read them, build them and propose changes.

The official repository ([lilos-plugins-official](https://github.com/GexyLab/lilos-plugins-official)) has lilOS's system apps. This one has the other apps and modules.

## Use it in lilOS

An administrator adds this repository once:

1. Open the **AppStore**, then **Options** (bottom right).
2. Choose **Add a repository**.
3. Enter `https://github.com/GexyLab/lilos-plugins-community`.

Its apps and modules then appear in the AppStore next to the official ones. lilOS installs the packages of the highest `vX.Y.Z` tag. Packages from a repository other than the official one are not verified, and the AppStore says so before installing them.

## What is here

| Folder | What | Notes |
|---|---|---|
| `apps/arduino-ide` | **ArduinoIDE4LilOS**: write, compile and upload sketches for Arduino Uno, Nano and Mega. It has suggestions while you type, a library manager, examples and a serial monitor. The board is plugged into your computer, and the browser talks to it with Web Serial (Chrome, Edge, Firefox 151+). | Needs lilOS 1.21.0+ and the `arduino` module |
| `modules/arduino` | Kernel module for ArduinoIDE4LilOS. It compiles sketches and installs libraries with arduino-cli, and gives the editor its suggestions with arduino-language-server and clangd. | An administrator installs it, then runs the setup |

`catalog.json` lists the package folders: it is what the AppStore reads. Each package folder has a `README.md`, which the AppStore shows in the package details.

How ArduinoIDE4LilOS works inside: [doc/arduino-ide.md](doc/arduino-ide.md).

## Structure

- `src/<app>/`: the sources of each app, with `app.json` (the template of the manifest) and `locales.json` (the translations, English first).
- `apps/<app>/`: the built package, with `lilos.json`, `dist/`, `locales.json` and `README.md`.
  - It is generated by `npm run build` and committed. lilOS installs these files as they are, without building anything.
  - `lilos.json` has the hash of every file, and the kernel checks them at install.
- `modules/<name>/`: a kernel module as it is: `module.json`, `index.js`, and a `package.json` with `package-lock.json` if it has dependencies.

The packages are installed byte for byte, so `.gitattributes` turns off every line ending conversion. Keep it that way.

The SDK and the APIs lilOS gives apps are documented in the lilOS repository: [doc/sviluppatore](https://github.com/GexyLab/lilos/tree/development/doc/sviluppatore).

## Build

```sh
npm ci
npm run build                  # every app
npm run build -- arduino-ide   # only one
```

The build stops in two cases:

- a language in `locales.json` lacks keys that English has;
- an app bundles a library, or a module downloads a program, that has no line in [THIRD_PARTY.md](THIRD_PARTY.md).

## Contribute

1. Fork the repository and make your change in `src/` or `modules/`.
2. Raise `version` in `src/<app>/app.json` or `modules/<name>/module.json`.
3. Translate every new or changed text the user sees, in English and Italian (`locales.json`; for a module, the `en`/`it` labels in `module.json`).
4. Run `npm run build` and commit both the sources and `apps/`.
5. Open a pull request. A maintainer merges it and tags a new version (`vX.Y.Z`), which lilOS installations then see as an update.

A new library goes into `package.json` with an exact version, and gets its line in `THIRD_PARTY.md`.
