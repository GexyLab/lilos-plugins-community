# v1.2.0 — 3 novembre 2026

## Compress Archive 2.0.0 (nuova in questo repository)

**Richiede lilOS 1.22.0** o successivo. Permessi: `fs.write:~` (leggere i file da comprimere e scrivere l'archivio accanto) e `ui.menus` (il menu **Comprimi** di file e cartelle).

- **Nuova funzionalità — arriva dal repository ufficiale.** Compress Archive crea ed estrae archivi zip (anche con password AES-256), 7z, tar, tar.gz, tar.bz2, tar.xz e iso, comprime ed estrae file singoli gz, bz2 e xz, ed estrae i rar (RAR 4 e 5). Ha la finestra con il contenuto dell'archivio, **Comprimi come…** e le azioni per Automata. *Perché qui:* non è un'app di sistema, e i suoi sorgenti, compreso il motore, sono aperti a tutti. È lo stesso pacchetto pubblicato nel repository ufficiale v1.53.0, identico byte per byte.
- **Compatibilità — chi l'ha installata dal repository ufficiale.** Compress Archive esce dal catalogo ufficiale (v1.54.0). Chi l'ha installata da lì la tiene e funziona, ma riceve gli aggiornamenti solo da questo repository: disinstallala e installala di nuovo da qui.
- **Compatibilità — chi ha ancora Zip.** Zip non è più in nessun catalogo. Installa Compress Archive da qui, poi disinstalla Zip; le automazioni registrate con Zip vanno registrate di nuovo.
- **Limiti.** Gli archivi rar non si possono creare (il formato è proprietario). La password vale solo per lo zip: i file cifrati di rar e 7z non si estraggono. Archivi e file estratti arrivano a 10 MB ciascuno, come ogni file di lilOS.
- **Documentazione.** README dell'app, README del repository, `doc/compress-archive.md` (come funziona dentro e come si ricostruisce il motore) e `THIRD_PARTY.md` con libarchive, zlib, bzip2, xz, Mbed TLS, Emscripten e musl.

## Come installarla

1. Se non l'hai già fatto, un amministratore aggiunge questo repository: AppStore → **Opzioni** → **Aggiungi un repository** → `https://github.com/GexyLab/lilos-plugins-community`.
2. AppStore → **Produttività** → **Compress Archive** → Installa. I pacchetti di questo repository non sono verificati: l'AppStore lo dice prima di installare.
